## 🍕 Featured: Level 3 — Crust & Craft Pizza Delivery Application

**"Good Pizza. Great Moments."**

A complete, production-ready full-stack pizza delivery web application built with a **Premium Dark Artistic Theme** (Charcoal Black `#171717`, Forest Green `#06110C`, and Crimson Red `#A31C18`).

### Core Features:
- 🍕 **Interactive Customizer:** Size, crust, extra toppings selection with real-time pricing calculation.
- 🛒 **Cart & Revalidation:** Client persistence + server-side validation against tampering.
- 💳 **Razorpay Payment Gateway:** Secure test-mode checkout with HMAC-SHA256 signature verification.
- 🚚 **Order Tracking:** Visual 5-stage live delivery timeline.
- 🔐 **Authentication:** JWT + 12-round bcrypt password hashing, role-based access.
- 🛠️ **Admin Management:** Comprehensive dashboard with revenue analytics, order status progression, and pizza menu CRUD operations.

👉 **Full documentation, setup instructions, and API endpoints can be found in the [Level 3 Project Folder README](./Web-Development-and-Designing-Level-3-Pizza-Delivery/README.md).**
